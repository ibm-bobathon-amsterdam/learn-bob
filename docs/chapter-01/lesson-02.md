# Lesson 2 — Your First Project

With the toolchain in place, create a minimal project and run it.

## Create a project directory

```sh
mkdir my-first-project
cd my-first-project
pnpm init
```

## Add a script

Create `index.js` and add the following content:

```js
console.log('Hello from my first project!')
```

Run it:

```sh
node index.js
```

You should see `Hello from my first project!` in the terminal.
