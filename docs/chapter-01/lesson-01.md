# Lesson 1 — Installation

This lesson walks you through installing the required tools and verifying your setup.

## Prerequisites

- Node.js 18 or later
- pnpm (`npm install -g pnpm`)

## Steps

1. Clone the repository.
2. Run `pnpm install` in the project root.
3. Confirm the toolchain by running `node --version`.

```sh
git clone https://github.com/ramonvanstijn/learn-bob.git
cd learn-bob
pnpm install
node --version  # should print v18 or later
```

You are now ready for [Lesson 2](./lesson-02).
